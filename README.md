# Purpose
A repository to store configuration files at home to use pi conveniently in multiple computers.

# Prerequistes
- Client side
  - pi is installed locally with pi-web-access extension installed.
  - $CRAWL4AI_API_TOKEN is setup at the client side.
- Service side
  - ollama is active and supported models pulled.
  - a docker instance of crawl4ai is up and running

# Setup
- On a client, download this folder.
- Create a folder ~/.pi/agent/, if not available yet.
- Copy all Json files to ~/.pi/agent/

# Run
- Run command "pi"
